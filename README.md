# BÀI THỰC HÀNH NODE.JS – HELLO NODE.JS

## 1. Thông tin sinh viên

- Trường: Kỹ thuật Công nghệ Nha Trang
- Họ và tên: Võ Thanh Hoài
- Lớp: CĐ-CNTT18A
- Mã sinh viên: CĐ-CNTT18A14

## 2. Nội dung thực hiện

- Cài đặt Node.js trên máy tính.
- Kiểm tra Node.js đã được cài đặt thành công.
- Tạo chương trình `hello.js`.
- Sử dụng `console.log()` để hiển thị nội dung ra màn hình.
- Hiển thị lời chào Node.js.
- Hiển thị họ và tên sinh viên.
- Thông báo Node.js đã được cài đặt thành công.

## 3. Nội dung file hello.js

```javascript
console.log("Xin chào Node.js!");
console.log("Họ và tên: Võ Thanh Hoài");
console.log("Node.js đã được cài đặt thành công!");
```

## 4. Hướng dẫn chạy chương trình

### Bước 1: Mở Terminal

Mở Terminal tại thư mục chứa file `hello.js`.

### Bước 2: Chạy chương trình

Thực hiện lệnh:

```bash
node hello.js
```

### Bước 3: Kiểm tra kết quả

Màn hình hiển thị:

```text
Xin chào Node.js!
Họ và tên: Võ Thanh Hoài
Node.js đã được cài đặt thành công!
```
